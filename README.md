# 💌 Сайт-признание «У тебя есть одно особенное письмо…»

Небольшое интерактивное романтическое приключение на чистых **HTML + CSS + JavaScript**
(без библиотек, фреймворков и backend).

Путь пользователя:

**конверт → письмо-признание → главный вопрос → убегающая кнопка «Нет» → «Да» → взрыв сердечек → финал с переходом в Telegram**

Фоном играет нежная музыка (включается при первом касании), а финальная кнопка копирует
тёплый текст и открывает чат в Telegram.

---

## 📁 Состав проекта

```
index.html   — разметка и текст признания
style.css    — весь дизайн, анимации, адаптив
script.js    — вся логика: переходы, печать текста, кнопка «Нет», эффекты, музыка, Telegram
music.mp3    — фоновая музыка (положи свой файл с этим именем)
README.md    — этот файл
```

---

## 🚀 Как запустить локально

Вариант 1 — просто открыть файл:

1. Скачай все 4 файла в одну папку.
2. Дважды кликни по `index.html` — сайт откроется в браузере.

Вариант 2 — через локальный сервер (рекомендуется, если подключаешь музыку):

```bash
# Python 3
python -m http.server 8000
# затем открой http://localhost:8000
```

```bash
# Node.js (если установлен npx)
npx serve
```

> Совет: чтобы точно проверить мобильную версию, открой в браузере режим разработчика (F12)
> и включи режим устройства (Device Toolbar) — выбери iPhone или Android.

## ✏️ Как изменить содержимое

### Текст признания

Открой **`index.html`**, найди блок:

```html
<div class="letter__body" id="letterBody">
  <p>Первый абзац…</p>
  <p>Второй абзац…</p>
</div>
```

Каждый `<p>` — отдельный абзац. Скрипт сам «напечатает» их по очереди.
Просто редактируй текст внутри тегов `<p>`. Добавлять/удалять абзацы можно свободно.

### Заголовок письма, вопрос, надписи и финал

Всё это — обычный текст в **`index.html`**. Меняй прямо там:

| Что | Где искать |
| --- | --- |
| «У тебя есть одно особенное письмо…» | класс `envelope-title` |
| «Открой меня 💗» | класс `envelope-cta` |
| Заголовок письма | класс `letter__title` |
| Вопрос «Будешь моей девушкой? 💗» | класс `question__text` |
| Подписи кнопок «Да» / «Нет» | `#yesBtn` / `#noBtn` |
| Финал «УРАААА! 💗» и текст | классы `final__title`, `final__text` |

### Кнопка «Продолжить в Telegram ✈️» (важно!)

Кнопка на финальном экране делает две вещи сразу:

1. **Копирует текст** в буфер обмена (по умолчанию «Я тебя люблю ❤️»).
2. **Открывает Telegram** по ссылке.

Обе настройки лежат в самом верху **`script.js`**:

```js
const TELEGRAM_URL = '';
const LOVE_TEXT = 'Я тебя люблю ❤️';
```

**Ссылка на Telegram.** Вставь свой ник или ссылку на чат:

```js
const TELEGRAM_URL = 'https://t.me/your_username';   // по нику
// или
const TELEGRAM_URL = 'https://t.me/+AbCdEfGhIjK';    // инвайт в группу/чат
```

Если оставить строку пустой, откроется общая страница `https://t.me/`. Лучше всё же вписать
свой ник — тогда кнопка приведёт прямо к тебе.

**Текст, который копируется.** Меняй `LOVE_TEXT` на что угодно:

```js
const LOVE_TEXT = 'Ты самая лучшая 💗';
```

После нажатия кнопки внизу экрана на пару секунд появится подсказка, что текст скопирован,
а Telegram откроется в новой вкладке. Девушке останется только вставить текст в чат.

### Фоновая музыка

Музыка уже подключена и запускается **сразу после открытия сайта**. Тебе нужно сделать всего одно:

1. Возьми любой музыкальный файл (`.mp3`, `.ogg` или `.wav`).
2. **Переименуй его в `music.mp3`** и положи в ту же папку, где лежат `index.html`,
   `style.css` и `script.js`.

```
папка проекта/
├── index.html
├── style.css
├── script.js
├── music.mp3      ← просто положи сюда файл с этим именем
└── README.md
```

**Как это работает.** Браузеры запрещают включать звук до первого действия пользователя.
Поэтому музыка пытается воспроизвестись моментально при открытии страницы. Если браузер
блокирует звук (это стандарт), она начнёт играть с самого первого касания или клика
(обычно это открытие конверта) — без задержек.

**Если файла нет** — сайт просто работает без музыки, никаких ошибок и предупреждений.

**Настройки** — в самом верху `script.js`:

```js
const MUSIC_URL = "music.mp3";   // имя файла в общей папке
const MUSIC_VOLUME = 0.55;       // громкость от 0 до 1
```

Меняй имя на любое другое. Пустая строка `""` — отключает музыку полностью.

### Музыка не играет на телефоне — чек-лист

На телефоне правила строже, чем на компьютере. Если на ПК играет, а на телефоне тихо:

1. **Перезалей проект на GitHub и обойди кэш.** После загрузки подожди пару минут,
   а на телефони открой ссылку с `?v=2` на конце — иначе браузер покажет старую версию.

2. **Проверь, что файл действительно доступен.** Открой на телефоне прямой адрес:

   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/music.m4a
   ```

   Если 404 — файл не долетел в репозиторий или называется иначе.

3. **Регистр букв важен.** Windows не различает `music.m4a` и `Music.m4a`,
   а GitHub Pages различает. Имя в репозитории должно быть символ в символ
   как в `MUSIC_URL`.

4. **Сними беззвучный режим на iPhone.** Боковой переключатель глушит звук веб-страниц.
   На Android проверь, что не включён режим «без звука» / «не беспокоить».

5. **Открывай в обычном браузере, а не внутри приложения.** Ссылки, открытые прямо
   в Telegram или Instagram, часто не получают право на звук. Выбери
   «Открыть в браузере» (Chrome / Safari).

6. **Нажми на конверт.** Первый тап даёт браузеру разрешение на звук. Если и после
   этого тихо — внизу появится подсказка «Нажми на экран, чтобы включить музыку 🔊»,
   нажми ещё раз.

## 🌐 Как разместить на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него все файлы проекта
   (включая `music.mp3`):

   ```bash
   git init
   git add .
   git commit -m "Romantic letter site"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```

2. В репозитории открой **Settings → Pages**.
3. В разделе **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)`
4. Нажми **Save** и подожди 1–2 минуты.
5. Сайт будет доступен по адресу:

   ```
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
   ```

Главный файл обязательно должен называться `index.html` — тогда он откроется сам.

## 📱 Как протестировать

**На компьютере**
- Открой `index.html`.
- Пройди все шаги: конверт → письмо → вопрос.
- Подвигай курсор к кнопке «Нет» — она должна убегать и оставлять сердечки.
- Нажми «Да» — должен быть взрыв сердечек и переход к финалу.

**На телефоне**
- Залей проект на GitHub Pages (или подними локальный сервер и зайди по IP компьютера).
- Проверь: письмо читается, строки не слишком длинные, кнопка «Нет» убегает от касания,
  нет горизонтальной прокрутки, ничего не «залипает».

**Что стоит проверить вручную**
- [ ] Кнопка «Да» срабатывает ровно один раз.
- [ ] Кнопка «Нет» не перекрывает кнопку «Да», сердце и текст вопроса.
- [ ] Текст письма можно показать целиком одним нажатием.
- [ ] Кнопка «Продолжить в Telegram ✈️» копирует текст и открывает Telegram.
- [ ] Фоновая музыка стартует сразу при открытии страницы.
- [ ] После финала кнопка «Пройти заново ↺» возвращает на конверт.
- [ ] В консоли браузера нет ошибок (F12 → Console).

## 🎨 Как поменять цвета и анимации

### Цвета

Все основные цвета собраны в начале **`style.css`** в блоке `:root`:

```css
:root {
  --pink-500: #ff4d8d;   /* нежно-розовый */
  --red-600:  #c81e4e;   /* красный */
  --wine-700: #7a1030;   /* бордовый */
  --wine-900: #2b0512;   /* тёмный фон */
}
```

Измени значения — и весь сайт перекрасится. Фоновый градиент задаётся в `body::before`.

### Скорость печати письма

В **`script.js`**:

```js
const TYPE_INTERVAL = 16;  // мс между шагами
const CHARS_PER_TICK = 2;  // сколько символов за шаг
```

Хочешь быстрее — увеличь `CHARS_PER_TICK` или уменьши `TYPE_INTERVAL`.

### Количество частиц

```js
const MAX_BG_ITEMS = 26;   // максимум фоновых частиц одновременно
```

Меньше значение — легче для слабых телефонов.

### Убегающая кнопка «Нет»

```js
const ESCAPE_COOLDOWN = 340; // пауза между прыжками, мс
const NO_PROXIMITY = 78;     // за сколько пикселей кнопка «чувствует» курсор
```

### Основные анимации

- покачивание конверта — `@keyframes envelopeWobble`
- пульс сердца — `@keyframes heartBeat`
- плавающие частицы — `@keyframes floatUp`
- взрыв сердечек — `@keyframes burst`
- мягкий всполох — `@keyframes softGlow`

## ♿ Доступность и производительность

- Поддержан режим **`prefers-reduced-motion`**: при включённом «уменьшении движения»
  тяжёлые анимации отключаются, а письмо показывается сразу.
- Частицы автоматически удаляются после анимации — интерфейс не «замусоривается».
- Количество одновременных частиц ограничено, чтобы не нагружать процессор телефона.
- Сайт адаптирован под Android, iPhone (с учётом «челки»), планшеты и компьютеры.
